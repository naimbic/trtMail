# trtMail deployment

Use the [Coolify deployment guide](coolify.md) and [.env.coolify.example](../.env.coolify.example).

The application runs on Node.js with persistent SQLite/file storage and your Ubuntu server's SMTP/IMAP services. The GitHub repository is `naimbic/trtMail`. The local folder is `/Users/trtdigital/gitRepos/trtMail`.

Historical Cloudflare configurations are retained for reference. They are not the deployment path for this version.
